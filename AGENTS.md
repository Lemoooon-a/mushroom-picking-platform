## Project progress reporting

When the user asks to synchronize, summarize, hand over, audit, or report the
current project progress, read and follow:

`docs/progress/REPORTING_GUIDE.md`

Examples of matching requests include:

- 同步当前进度
- 总结当前工程状态
- 生成项目交接报告
- 更新进度文档
- what is the current project status
- prepare a handoff report

The repository reporting guide is the source of truth for project progress
reports.

Do not stop merely because an optional external reporting skill, template, or
referenced specification file is missing. Continue using the repository guide
and mention the missing optional dependency briefly in the final report.

Unless the user explicitly asks for a chat-only summary, update:

`docs/progress/CURRENT_STATUS.md`

Progress reports must be based on repository evidence. Do not infer completed
hardware validation from successful compilation.
