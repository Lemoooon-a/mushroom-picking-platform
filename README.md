# Mushroom Picking Platform

基于滑轨 SCARA 机械臂的蘑菇采摘平台。

## 系统组成

- 滑轨步进电机
- Z 轴步进电机
- 两个瓴控 MG4010E-i36 CAN 关节电机
- 末端总线舵机
- 吸盘及真空检测
- Intel RealSense 深度相机
- 上位机控制程序
- STM32 步进与 IO 控制器

## 目录结构

- `docs/`：系统设计、电气连接、协议和标定文档
- `host/`：上位机控制程序
- `firmware/`：STM32 固件
- `tools/`：电机测试、标定和调试工具
- `config/`：机器人配置模板
